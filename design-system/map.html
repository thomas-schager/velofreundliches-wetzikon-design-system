Karten (Leaflet)

Jede Karte im Projekt — die VeloMelder-Hauptkarte und ihr Routen-Editor in velo-melder.html, die öffentlichen Velonetz-Einbettungen (velo-velonetz-embed-3.html) und die Meldungs-Prüfkarte im Admin-Backend — ist Leaflet 1.9.4 mit demselben Kartenstil, denselben Kachel-Anbietern und denselben Pin-Markern. Diese Seite ist die kanonische Referenz für dieses "Look & Feel"; velo-melder.html in velofreundliches-wetzikon-contao bleibt die Quelle, aus der es hierher übertragen wurde (siehe Wo verwendet).

Leaflet-Version fixieren.

Alle Kartenflächen laden Leaflet 1.9.4 von derselben CDN (cdnjs.cloudflare.com/ajax/libs/leaflet/1.9.4/). Eine neue Karte, die eine andere Version oder einen anderen CDN-Host lädt, kann optisch/funktional abweichen (Icon-Anchor-Berechnung, Popup-Layout) — beim Hinzufügen einer Karte immer diese Version übernehmen, nicht "die neueste".

Kartenstil L.tileLayer
Kartenebenen

Zwei Ebenen, umschaltbar über den Stil-Toggle (siehe Container & Steuerelemente). Strasse ist immer die Standardebene beim Laden.

Strasse (Standard)
var CARTO_API_KEY = 'cb1_2wxo_1_5095e615a6275239af744999'; // carto.com/basemaps/apikey

L.tileLayer('https://{s}.basemaps.cartocdn.com/rastertiles/voyager/{z}/{x}/{y}{r}.png?key=' + CARTO_API_KEY, {
  attribution: '&copy; OpenStreetMap contributors &copy; CARTO',
  subdomains: 'abcd',
  maxZoom: 19
})

CARTO Voyager — helle, reduzierte Farbgebung, damit Routen/Pins/Bänder die Aufmerksamkeit behalten (kein OSM-Standardstil mit lauten POI-Icons). Seit 2026-08 verlangt basemaps.cartocdn.com einen API-Key, sonst überklebt jede Kachel ein "API KEY REQUIRED"-Wasserzeichen (Request schlägt nicht fehl, sieht nur kaputt aus). Kostenloser Key ohne CARTO-Account: carto.com/basemaps/apikey — der Key oben ist auf die Produktions-Domain registriert; bei einem anderen Host (z.B. lokale Entwicklung) ggf. einen eigenen anfordern. CARTO baut die Raster-Basemaps langfristig zugunsten von Vektor-Kacheln ab — falls dieser Dienst irgendwann ganz wegfällt, ist Standard-OpenStreetMap ({s}.tile.openstreetmap.org/{z}/{x}/{y}.png, kein Key nötig) der dokumentierte Fallback.

Satellit (umschaltbar)
L.tileLayer('https://server.arcgisonline.com/ArcGIS/rest/services/World_Imagery/MapServer/tile/{z}/{y}/{x}', {
  attribution: '&copy; Esri',
  maxZoom: 19
})

Esri World Imagery — nützlich, um vor Ort tatsächliche Verhältnisse (z.B. Belagszustand) zu beurteilen; nicht die Standardebene, weil sie für die reine Routenübersicht schlechter lesbar ist.

Bewertungs-Pins L.divIcon
Bewertungs-Pins

Meldungen werden nie mit Leaflets Standard-Marker angezeigt, sondern mit einem Tropfen-Pin, dessen Farbe die Bewertung codiert — dieselben fünf Farben wie --color-rate-1…--color-rate-5 auf der Tokens-Seite, damit Bewertungsfarbe auf Karte, in Badges und in Formularen überall identisch ist.

JS zum Kopieren
function makeIcon(rating) {
  var color = RATING_COLORS[rating]; // --color-rate-1 … --color-rate-5
  var svg = '<svg viewBox="0 0 24 32" xmlns="http://www.w3.org/2000/svg">'
    + '<path d="M12 0C5.37 0 0 5.37 0 12c0 8.5 12 20 12 20S24 20.5 24 12'
    +      'C24 5.37 18.63 0 12 0z" fill="' + color + '"/>'
    + '<circle cx="12" cy="12" r="5" fill="rgba(255,255,255,0.35)"/>'
    + '</svg>';
  return L.divIcon({
    html: '<div class="custom-pin">' + svg + '</div>',
    iconSize: [24, 32], iconAnchor: [12, 32], popupAnchor: [0, -34], className: ''
  });
}

Teardrop + halbtransparenter Mittelkreis, kein Leaflet-Standard-Icon-Bild. iconAnchor: [12, 32] setzt die Pin-Spitze exakt auf die Koordinate.

CSS
.custom-pin { width: 24px; height: 32px; }
.custom-pin svg { width: 100%; height: 100%; filter: drop-shadow(0 2px 4px rgba(0,0,0,0.22)); }
Container & Steuerelemente site.css
Container & Steuerelemente
  • Karten-Container: border-radius: var(--radius-sm) (kleine Inline-Karten, z.B. .adm-detail-map) oder var(--radius-md)/var(--radius-lg) für grössere Panels, plus overflow: hidden und border: 1px solid var(--color-border) — nie eine randlose Vollbild-Karte ausserhalb eines dedizierten Vollbild-Kontexts.
  • Stil-Toggle (Strasse/Satellit): oben rechts, position: absolute; top: 12px; right: 12px;, als zusammenhängende Button-Gruppe mit var(--shadow-md), aktiver Zustand dunkel gefüllt (var(--color-secondary)) — siehe Markup unten.
  • Leaflets eigene Zoom-Controls bleiben Standard-Position (bottomright in Formularen, wo der Toggle oben rechts sitzt); Klicks auf Toggle/Zoom dürfen nie an darunterliegende Karten-Click-Handler durchgereicht werden (L.DomEvent.disableClickPropagation).
  • Popup-Schliessen-Button: font-size: 16px !important; color: var(--color-muted) !important; — Leaflets Default wirkt sonst zu klein/kontrastarm neben den übrigen UI-Elementen.

Beispiel Vollständiges Setup
Markup/CSS/JS zum Kopieren
<link rel="stylesheet" href="https://cdnjs.cloudflare.com/ajax/libs/leaflet/1.9.4/leaflet.min.css">
<script src="https://cdnjs.cloudflare.com/ajax/libs/leaflet/1.9.4/leaflet.min.js"></script>

<div id="map"></div>
<div class="map-toggle">
  <button class="map-toggle-btn active" onclick="setLayer('street')">Strasse</button>
  <button class="map-toggle-btn" onclick="setLayer('satellite')">Satellit</button>
</div>

<script>
var CARTO_API_KEY = 'cb1_2wxo_1_5095e615a6275239af744999'; // carto.com/basemaps/apikey
var map = L.map('map', { center: [47.3235, 8.7985], zoom: 15 });
var LAYERS = {
  street:    L.tileLayer('https://{s}.basemaps.cartocdn.com/rastertiles/voyager/{z}/{x}/{y}{r}.png?key=' + CARTO_API_KEY,
               { attribution: '&copy; OpenStreetMap contributors &copy; CARTO', subdomains: 'abcd', maxZoom: 19 }),
  satellite: L.tileLayer('https://server.arcgisonline.com/ArcGIS/rest/services/World_Imagery/MapServer/tile/{z}/{y}/{x}',
               { attribution: '&copy; Esri', maxZoom: 19 })
};
var currentLayer = 'street';
LAYERS.street.addTo(map);

function setLayer(name) {
  if (name === currentLayer) return;
  map.removeLayer(LAYERS[currentLayer]);
  LAYERS[name].addTo(map);
  currentLayer = name;
  document.querySelectorAll('.map-toggle-btn').forEach(function (b) {
    b.classList.toggle('active', b.textContent.trim() === (name === 'street' ? 'Strasse' : 'Satellit'));
  });
}
</script>

Gekürzt (kein Event-Delegation-Boilerplate) — die vollständige, produktive Fassung inkl. Click-Propagation-Guards steht in velo-melder.html, Marker COMPILE:MAP-ENGINE.
